Lista de Exercícios - Decisão com if...else em Java usando JOptionPane

Esta lista contém 10 questões de algoritmos envolvendo estrutura de decisão, sendo 5 de nível fácil e 5 de nível médio-fácil. As respostas estão escritas em Java usando a classe JOptionPane para entrada e saída de dados.

Questão 1 - Número positivo ou negativo

Nível: Fácil

Crie um programa que leia um número inteiro e informe se ele é positivo ou negativo.

import javax.swing.JOptionPane;

public class Questao01 {
    public static void main(String[] args) {
        int numero;

        numero = Integer.parseInt(
            JOptionPane.showInputDialog("Digite um número inteiro:")
        );

        if (numero >= 0) {
            JOptionPane.showMessageDialog(null, "O número é positivo.");
        } else {
            JOptionPane.showMessageDialog(null, "O número é negativo.");
        }
    }
}

Questão 6 - Maior entre dois números

Nível: Médio-fácil

Crie um programa que leia dois números inteiros e informe qual deles é o maior. Caso sejam iguais, informe que os valores são iguais.

import javax.swing.JOptionPane;

public class Questao06 {
    public static void main(String[] args) {
        int n1, n2;

        n1 = Integer.parseInt(
            JOptionPane.showInputDialog("Digite o primeiro número:")
        );

        n2 = Integer.parseInt(
            JOptionPane.showInputDialog("Digite o segundo número:")
        );

        if (n1 > n2) {
            JOptionPane.showMessageDialog(null, "O maior número é: " + n1);
        } else {
            if (n2 > n1) {
                JOptionPane.showMessageDialog(null, "O maior número é: " + n2);
            } else {
                JOptionPane.showMessageDialog(null, "Os dois números são iguais.");
            }
        }
    }
}

Questão 7 - Média de duas notas

Nível: Médio-fácil

Crie um programa que leia duas notas de um aluno, calcule a média e informe se ele foi aprovado ou reprovado. Considere aprovado quem tiver média maior ou igual a 7.

import javax.swing.JOptionPane;

public class Questao07 {
    public static void main(String[] args) {
        double nota1, nota2, media;

        nota1 = Double.parseDouble(
            JOptionPane.showInputDialog("Digite a primeira nota:")
        );

        nota2 = Double.parseDouble(
            JOptionPane.showInputDialog("Digite a segunda nota:")
        );

        media = (nota1 + nota2) / 2;

        if (media >= 7) {
            JOptionPane.showMessageDialog(null, "Média: " + media + "\nAluno aprovado.");
        } else {
            JOptionPane.showMessageDialog(null, "Média: " + media + "\nAluno reprovado.");
        }
    }
}

Questão 8 - Desconto em compra

Nível: Médio-fácil

Crie um programa que leia o valor de uma compra. Se o valor for maior ou igual a R$ 100,00, aplique um desconto de 10%. Caso contrário, não aplique desconto. Ao final, mostre o valor final da compra.

import javax.swing.JOptionPane;

public class Questao08 {
    public static void main(String[] args) {
        double valorCompra, valorFinal;

        valorCompra = Double.parseDouble(
            JOptionPane.showInputDialog("Digite o valor da compra:")
        );

        if (valorCompra >= 100) {
            valorFinal = valorCompra - (valorCompra * 0.10);
        } else {
            valorFinal = valorCompra;
        }

        JOptionPane.showMessageDialog(null, "Valor final da compra: R$ " + valorFinal);
    }
}

Questão 10 - Cálculo de salário com bônus

Nível: Médio-fácil

Crie um programa que leia o salário de um funcionário. Se o salário for menor ou igual a R$ 1500,00, aplique um bônus de R$ 200,00. Caso contrário, aplique um bônus de R$ 100,00. Ao final, mostre o novo salário.

import javax.swing.JOptionPane;

public class Questao10 {
    public static void main(String[] args) {
        double salario, novoSalario;

        salario = Double.parseDouble(
            JOptionPane.showInputDialog("Digite o salário do funcionário:")
        );

        if (salario <= 1500) {
            novoSalario = salario + 200;
        } else {
            novoSalario = salario + 100;
        }

        JOptionPane.showMessageDialog(null, "Novo salário: R$ " + novoSalario);
    }
}
