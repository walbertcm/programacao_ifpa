Questão 1

Crie um algoritmo que leia um número inteiro. Se o número for positivo, mostre a mensagem: "Número positivo".

algoritmo "verifica_numero_positivo"

var
   numero: inteiro

inicio
   escreva("Digite um número inteiro: ")
   leia(numero)

   se numero > 0 entao
      escreval("Número positivo.")
   fimse

fimalgoritmo

Questão 6

Crie um algoritmo que leia o valor de uma compra. Se o valor for maior ou igual a R$ 100,00, aplique um desconto de 10% e mostre o valor final com desconto.

algoritmo "desconto_compra"

var
   valorCompra, valorFinal: real

inicio
   escreva("Digite o valor da compra: R$ ")
   leia(valorCompra)

   se valorCompra >= 100 entao
      valorFinal <- valorCompra - (valorCompra * 0.10)
      escreval("Valor final com desconto: R$ ", valorFinal)
   fimse

fimalgoritmo

Questão 7

Crie um algoritmo que leia duas notas de um aluno e calcule a média. Se a média for maior ou igual a 7, mostre a média e a mensagem: "Aluno aprovado".

algoritmo "media_aprovacao"

var
   nota1, nota2, media: real

inicio
   escreva("Digite a primeira nota: ")
   leia(nota1)

   escreva("Digite a segunda nota: ")
   leia(nota2)

   media <- (nota1 + nota2) / 2

   se media >= 7 entao
      escreval("Média: ", media)
      escreval("Aluno aprovado.")
   fimse

fimalgoritmo

Questão 9

Crie um algoritmo que leia o salário de um funcionário. Se o salário for menor ou igual a R$ 1500,00, aplique um bônus de R$ 200,00 e mostre o novo salário.

algoritmo "bonus_salario"

var
   salario, novoSalario: real

inicio
   escreva("Digite o salário do funcionário: R$ ")
   leia(salario)

   se salario <= 1500 entao
      novoSalario <- salario + 200
      escreval("Novo salário: R$ ", novoSalario)
   fimse

fimalgoritmo
