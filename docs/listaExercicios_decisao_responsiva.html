Questão 1

Crie um algoritmo que leia um número inteiro e informe se ele é positivo ou negativo.

algoritmo "positivo_ou_negativo"

var
   numero: inteiro

inicio
   escreva("Digite um número inteiro: ")
   leia(numero)

   se numero >= 0 entao
      escreval("O número é positivo.")
   senao
      escreval("O número é negativo.")
   fimse

Questão 7

Crie um algoritmo que leia duas notas de um aluno, calcule a média e informe se ele foi aprovado ou reprovado. Considere aprovado quem tiver média maior ou igual a 7.

algoritmo "media_duas_notas"

var
   nota1, nota2, media: real

inicio
   escreva("Digite a primeira nota: ")
   leia(nota1)

   escreva("Digite a segunda nota: ")
   leia(nota2)

   media <- (nota1 + nota2) / 2

   escreval("Média: ", media)

   se media >= 7 entao
      escreval("Aluno aprovado.")
   senao
      escreval("Aluno reprovado.")
   fimse

Questão 8

Crie um algoritmo que leia o valor de uma compra. Se o valor for maior ou igual a R$ 100,00, aplique um desconto de 10%. Caso contrário, não aplique desconto. Ao final, mostre o valor final da compra.

algoritmo "desconto_compra"

var
   valorCompra, valorFinal: real

inicio
   escreva("Digite o valor da compra: R$ ")
   leia(valorCompra)

   se valorCompra >= 100 entao
      valorFinal <- valorCompra - (valorCompra * 0.10)
   senao
      valorFinal <- valorCompra
   fimse

   escreval("Valor final da compra: R$ ", valorFinal)

fimalgoritmo

Questão 10

Crie um algoritmo que leia o salário de um funcionário. Se o salário for menor ou igual a R$ 1500,00, aplique um bônus de R$ 200,00. Caso contrário, aplique um bônus de R$ 100,00. Ao final, mostre o novo salário.

algoritmo "salario_com_bonus"

var
   salario, novoSalario: real

inicio
   escreva("Digite o salário do funcionário: R$ ")
   leia(salario)

   se salario <= 1500 entao
      novoSalario <- salario + 200
   senao
      novoSalario <- salario + 100
   fimse

   escreval("Novo salário: R$ ", novoSalario)

fimalgoritmo
