Bem-vindo ao Portal da Disciplina

Esta página reúne materiais didáticos das disciplinas de Algoritmos, Programação e Estrutura de Dados. Aqui você encontrará apostilas, listas de exercícios e conteúdos complementares desenvolvidos para apoiar o aprendizado de lógica de programação e o desenvolvimento do pensamento computacional. Os conteúdos estão organizados de maneira progressiva, iniciando pelos conceitos básicos de algoritmos e avançando gradualmente para estruturas e técnicas mais complexas da programação.

Recomenda-se iniciar pelos materiais de Algoritmos, avançar para os fundamentos de Programação e, em seguida, estudar os conteúdos de Estrutura de Dados. Essa sequência favorece uma aprendizagem gradual, conectando teoria, prática e resolução de problemas.
