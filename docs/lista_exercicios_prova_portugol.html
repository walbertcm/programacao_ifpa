Questão 1 — Menu de opções

Faça um programa que mostre o menu de opções a seguir, receba a opção do usuário e os dados necessários para executar cada operação.

Menu de opções:

  1. Somar dois números.
  2. Raiz quadrada de um número.

Digite a opção desejada.

Resposta em Portugol

algoritmo "menu_opcoes"

var
   num1, num2, soma, raiz: real
   op: inteiro

inicio
   escreval("MENU")
   escreval("1 - Somar dois números")
   escreval("2 - Raiz quadrada de um número")
   escreva("Digite a opção desejada: ")
   leia(op)

   se op = 1 entao
      escreva("Digite o primeiro número: ")
      leia(num1)

      escreva("Digite o segundo número: ")
      leia(num2)

      soma <- num1 + num2

      escreval("A soma de ", num1, " e ", num2, " é ", soma)
   senao
      se op = 2 entao
         escreva("Digite um número: ")
         leia(num1)

         se num1 >= 0 entao
            raiz <- raizq(num1)
            escreval("A raiz quadrada de ", num1, " é ", raiz)
         senao
            escreval("Não existe raiz quadrada real para número negativo.")
         fimse
      senao
         escreval("Opção inválida!")
      fimse
   fimse

Questão 2

Questão 2 — Potências e raízes

Faça um programa que receba um número positivo e maior que zero, calcule e mostre:

  1. o número digitado ao quadrado;
  2. o número digitado ao cubo;
  3. a raiz quadrada do número digitado;
  4. a raiz cúbica do número digitado.

Resposta em Portugol

algoritmo "potencias_e_raizes"

var
   numero, quadrado, cubo, raiz_quadrada, raiz_cubica: real

inicio
   escreva("Digite um número positivo e maior que zero: ")
   leia(numero)

   se numero > 0 entao
      quadrado <- numero ^ 2
      cubo <- numero ^ 3
      raiz_quadrada <- raizq(numero)
      raiz_cubica <- numero ^ (1.0 / 3.0)

      escreval("Número ao quadrado: ", quadrado)
      escreval("Número ao cubo: ", cubo)
      escreval("Raiz quadrada: ", raiz_quadrada)
      escreval("Raiz cúbica: ", raiz_cubica)
   senao
      escreval("O número deve ser positivo e maior que zero.")
   fimse

Questão 3 — Cargo e aumento salarial

Faça um programa que receba o código correspondente ao cargo de um funcionário e seu salário atual e mostre o cargo, o valor do aumento e seu novo salário. Os cargos estão na tabela a seguir.

Código Cargo Percentual de aumento
1Escriturário50%
2Secretário35%
3Caixa20%
4Gerente10%
5DiretorNão tem aumento

Resposta em Portugol

algoritmo "cargo_e_aumento"

var
   cargo: inteiro
   salario, aumento, novo_salario: real

inicio
   escreva("Digite o código do cargo do funcionário (1, 2, 3, 4 ou 5): ")
   leia(cargo)

   escreva("Digite o salário atual: ")
   leia(salario)

   escolha cargo
      caso 1
         escreval("Cargo: Escriturário")
         aumento <- salario * 50 / 100

      caso 2
         escreval("Cargo: Secretário")
         aumento <- salario * 35 / 100

      caso 3
         escreval("Cargo: Caixa")
         aumento <- salario * 20 / 100

      caso 4
         escreval("Cargo: Gerente")
         aumento <- salario * 10 / 100

      caso 5
         escreval("Cargo: Diretor")
         aumento <- 0

      outrocaso
         escreval("Cargo inexistente!")
         aumento <- -1
   fimescolha

   se aumento >= 0 entao
      novo_salario <- salario + aumento
      escreval("Valor do aumento: R$ ", aumento:8:2)
      escreval("Novo salário: R$ ", novo_salario:8:2)
   fimse

Questão 4 — Categoria de um nadador

Categoria Idade
Infantil5 a 7
Juvenil8 a 10
Adolescente11 a 15
Adulto16 a 30
SêniorAcima de 30

Resposta em Portugol

algoritmo "categoria_nadador"

var
   idade: inteiro

inicio
   escreva("Digite a idade do nadador: ")
   leia(idade)

   se idade < 5 entao
      escreval("Não existe categoria para esta idade.")
   senao
      se idade <= 7 entao
         escreval("Categoria: Infantil")
      senao
         se idade <= 10 entao
            escreval("Categoria: Juvenil")
         senao
            se idade <= 15 entao
               escreval("Categoria: Adolescente")
            senao
               se idade <= 30 entao
                  escreval("Categoria: Adulto")
               senao
                  escreval("Categoria: Sênior")
               fimse
            fimse
         fimse
      fimse
   fimse

Questão 5 — Jogo de adivinhação

Faça um programa que implemente um jogo de adivinhação. O programa deverá definir um número secreto igual a 7 e permitir que o jogador tente descobrir esse número.

O jogador terá 5 tentativas. A cada tentativa:

  • Leia um número informado pelo jogador.
  • Se o número for igual ao número secreto, mostre a mensagem "Parabéns! Você acertou!".
  • Se o número digitado for menor que o número secreto, mostre a mensagem "O número secreto é maior.".
  • Se o número digitado for maior que o número secreto, mostre a mensagem "O número secreto é menor.".

Caso o jogador não acerte após as 5 tentativas, mostre a mensagem "Fim de jogo! O número secreto era 7.".

Resposta em Portugol

algoritmo "jogo_adivinhacao"

var
   numero, secreto, tentativa: inteiro
   acertou: logico

inicio
   secreto <- 7
   acertou <- falso

   escreval("=== JOGO DE ADIVINHAÇÃO ===")
   escreval("Tente descobrir o número secreto.")
   escreval("Você possui 5 tentativas.")

   para tentativa de 1 ate 5 faca

      se acertou = falso entao

         escreva("Tentativa ", tentativa, ": ")
         leia(numero)

         se numero = secreto entao
            escreval("Parabéns! Você acertou!")
            acertou <- verdadeiro
         senao

            se numero < secreto entao
               escreval("O número secreto é maior.")
            senao
               escreval("O número secreto é menor.")
            fimse

         fimse

      fimse

   fimpara

   se acertou = falso entao
      escreval("Fim de jogo!")
      escreval("O número secreto era ", secreto, ".")
   fimse
