Questão 1

Questão 1 — Classificação de nota

Crie um algoritmo que leia a nota de um aluno e apresente uma das classificações:

  • Aprovado, quando a nota for maior ou igual a 7;
  • Recuperação, quando a nota estiver entre 4 e 6,9;
  • Reprovado, quando a nota for menor que 4.

Resposta em Portugol

algoritmo "classificacao_nota"

var
   nota: real

inicio
   escreva("Digite a nota do aluno: ")
   leia(nota)

   se nota >= 7 entao
      escreval("Situação: Aprovado.")
   senao
      se nota >= 4 entao
         escreval("Situação: Recuperação.")
      senao
         escreval("Situação: Reprovado.")
      fimse
   fimse

Questão 4

Questão 4 — Cálculo de área de figuras geométricas

Crie um algoritmo que leia um código correspondente a uma figura geométrica:

  1. Quadrado
  2. Retângulo
  3. Triângulo

De acordo com a opção escolhida, solicite os valores necessários e calcule a área:

  • Quadrado: área = lado × lado;
  • Retângulo: área = base × altura;
  • Triângulo: área = (base × altura) / 2.

Ao final, informe a área calculada. Caso seja informado outro código, exiba a mensagem “Figura inválida.”

Resposta em Portugol

algoritmo "area_figuras"

var
   codigo: inteiro
   lado, base, altura, area: real

inicio
   escreval("1 - Quadrado")
   escreval("2 - Retângulo")
   escreval("3 - Triângulo")
   escreva("Digite o código da figura: ")
   leia(codigo)

   se codigo = 1 entao
      escreva("Digite o lado do quadrado: ")
      leia(lado)

      area <- lado * lado
      escreval("Área do quadrado: ", area)
   senao
      se codigo = 2 entao
         escreva("Digite a base do retângulo: ")
         leia(base)
         escreva("Digite a altura do retângulo: ")
         leia(altura)

         area <- base * altura
         escreval("Área do retângulo: ", area)
      senao
         se codigo = 3 entao
            escreva("Digite a base do triângulo: ")
            leia(base)
            escreva("Digite a altura do triângulo: ")
            leia(altura)

            area <- (base * altura) / 2
            escreval("Área do triângulo: ", area)
         senao
            escreval("Figura inválida.")
         fimse
      fimse
   fimse

Questão 5

Questão 5 — Cálculo de salário por categoria

Crie um algoritmo que leia o salário-base de um funcionário e sua categoria profissional:

  1. Estagiário: recebe o salário-base, sem acréscimo;
  2. Assistente: recebe acréscimo de 10%;
  3. Analista: recebe acréscimo de 20%;
  4. Gerente: recebe acréscimo de 30%.

O algoritmo deve calcular e informar o salário final conforme a categoria. Caso a categoria seja inválida, apresente uma mensagem de erro.

Resposta em Portugol

algoritmo "salario_por_categoria"

var
   categoria: inteiro
   salarioBase, salarioFinal: real

inicio
   escreva("Digite o salário-base: R$ ")
   leia(salarioBase)

   escreval("1 - Estagiário")
   escreval("2 - Assistente")
   escreval("3 - Analista")
   escreval("4 - Gerente")
   escreva("Digite a categoria: ")
   leia(categoria)

   se categoria = 1 entao
      salarioFinal <- salarioBase
      escreval("Salário final: R$ ", salarioFinal)
   senao
      se categoria = 2 entao
         salarioFinal <- salarioBase * 1.10
         escreval("Salário final: R$ ", salarioFinal)
      senao
         se categoria = 3 entao
            salarioFinal <- salarioBase * 1.20
            escreval("Salário final: R$ ", salarioFinal)
         senao
            se categoria = 4 entao
               salarioFinal <- salarioBase * 1.30
               escreval("Salário final: R$ ", salarioFinal)
            senao
               escreval("Categoria inválida.")
            fimse
         fimse
      fimse
   fimse
