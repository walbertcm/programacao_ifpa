Lista de Exercícios - Decisão com if...else em Java

Esta lista contém 10 questões de algoritmos envolvendo estrutura de decisão, sendo 5 de nível fácil e 5 de nível médio-fácil. As respostas estão escritas em Java.

Questão 1 - Número positivo ou negativo

Nível: Fácil

Crie um programa que leia um número inteiro e informe se ele é positivo ou negativo.

import java.util.Scanner;

public class Questao01 {
    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);

        int numero;

        System.out.print("Digite um número inteiro: ");
        numero = entrada.nextInt();

        if (numero >= 0) {
            System.out.println("O número é positivo.");
        } else {
            System.out.println("O número é negativo.");
        }

        entrada.close();
    }
}

Questão 6 - Maior entre dois números

Nível: Médio-fácil

Crie um programa que leia dois números inteiros e informe qual deles é o maior. Caso sejam iguais, informe que os valores são iguais.

import java.util.Scanner;

public class Questao06 {
    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);

        int n1, n2;

        System.out.print("Digite o primeiro número: ");
        n1 = entrada.nextInt();

        System.out.print("Digite o segundo número: ");
        n2 = entrada.nextInt();

        if (n1 > n2) {
            System.out.println("O maior número é: " + n1);
        } else {
            if (n2 > n1) {
                System.out.println("O maior número é: " + n2);
            } else {
                System.out.println("Os dois números são iguais.");
            }
        }

        entrada.close();
    }
}

Questão 7 - Média de duas notas

Nível: Médio-fácil

Crie um programa que leia duas notas de um aluno, calcule a média e informe se ele foi aprovado ou reprovado. Considere aprovado quem tiver média maior ou igual a 7.

import java.util.Scanner;

public class Questao07 {
    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);

        double nota1, nota2, media;

        System.out.print("Digite a primeira nota: ");
        nota1 = entrada.nextDouble();

        System.out.print("Digite a segunda nota: ");
        nota2 = entrada.nextDouble();

        media = (nota1 + nota2) / 2;

        System.out.println("Média: " + media);

        if (media >= 7) {
            System.out.println("Aluno aprovado.");
        } else {
            System.out.println("Aluno reprovado.");
        }

        entrada.close();
    }
}

Questão 8 - Desconto em compra

Nível: Médio-fácil

Crie um programa que leia o valor de uma compra. Se o valor for maior ou igual a R$ 100,00, aplique um desconto de 10%. Caso contrário, não aplique desconto. Ao final, mostre o valor final da compra.

import java.util.Scanner;

public class Questao08 {
    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);

        double valorCompra, valorFinal;

        System.out.print("Digite o valor da compra: R$ ");
        valorCompra = entrada.nextDouble();

        if (valorCompra >= 100) {
            valorFinal = valorCompra - (valorCompra * 0.10);
        } else {
            valorFinal = valorCompra;
        }

        System.out.println("Valor final da compra: R$ " + valorFinal);

        entrada.close();
    }
}

Questão 10 - Cálculo de salário com bônus

Nível: Médio-fácil

Crie um programa que leia o salário de um funcionário. Se o salário for menor ou igual a R$ 1500,00, aplique um bônus de R$ 200,00. Caso contrário, aplique um bônus de R$ 100,00. Ao final, mostre o novo salário.

import java.util.Scanner;

public class Questao10 {
    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);

        double salario, novoSalario;

        System.out.print("Digite o salário do funcionário: R$ ");
        salario = entrada.nextDouble();

        if (salario <= 1500) {
            novoSalario = salario + 200;
        } else {
            novoSalario = salario + 100;
        }

        System.out.println("Novo salário: R$ " + novoSalario);

        entrada.close();
    }
}
