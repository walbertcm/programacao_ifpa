Lista de Exercícios de Algoritmos

Questão 1

Analise o algoritmo abaixo e informe qual será o valor impresso.

  prog q1
  int x;
  x <- 10;
  imprima x;
fimprog
  
      algoritmo "q1"
      var
        x: inteiro
      inicio
        x <- 10
        escreval(x)
      fimalgoritmo

Questão 2

Qual será a saída do algoritmo abaixo?

prog q2
int x;
x <- 10;
imprima "Valor de x = ", x;
fimprog
  
algoritmo "q2"

var
   x: inteiro

inicio
   x <- 10
   escreval("Valor de x = ", x)

fimalgoritmo
Saída: 
Valor de x = 10

Questão 10

Crie um algoritmo que leia um valor inteiro, um número real, um nome (caractere) e um valor lógico. Em seguida, imprima todos os valores informados.

algoritmo "q10"

var
   x: inteiro
   r: real
   nome: caractere
   status: logico

inicio
   escreva("Digite um numero inteiro: ")
   leia(x)

   escreva("Digite um numero real: ")
   leia(r)

   escreva("Digite um nome: ")
   leia(nome)

   escreva("Digite verdadeiro ou falso: ")
   leia(status)

   escreval("Inteiro: ", x)
   escreval("Real: ", r)
   escreval("Nome: ", nome)
   escreval("Logico: ", status)

fimalgoritmo
