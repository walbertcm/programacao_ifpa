Questão 1

Questão 1 — Maior número entre dez valores

Leia 10 números e informe qual foi o maior valor digitado.

Resposta em Portugol

algoritmo "maior_dez_numeros"

var
   i, numero, maior: inteiro

inicio
   para i de 1 ate 10 faca
      escreva("Digite o ", i, "º número: ")
      leia(numero)

      se i = 1 entao
         maior <- numero
      senao
         se numero > maior entao
            maior <- numero
         fimse
      fimse
   fimpara

   escreval("Maior número: ", maior)

Questão 3 — Positivos, negativos e zeros

Leia 15 números inteiros e informe quantos são positivos, quantos são negativos e quantos são iguais a zero.

Resposta em Portugol

algoritmo "classificar_numeros"

var
   i, numero, positivos, negativos, zeros: inteiro

inicio
   positivos <- 0
   negativos <- 0
   zeros <- 0

   para i de 1 ate 15 faca
      escreva("Digite um número: ")
      leia(numero)

      se numero > 0 entao
         positivos <- positivos + 1
      senao
         se numero < 0 entao
            negativos <- negativos + 1
         senao
            zeros <- zeros + 1
         fimse
      fimse
   fimpara

   escreval("Positivos: ", positivos)
   escreval("Negativos: ", negativos)
   escreval("Zeros: ", zeros)

Questão 4 — Fatorial de um número

Leia um número inteiro não negativo e calcule seu fatorial. Exemplo: 5! = 5 × 4 × 3 × 2 × 1 = 120.

Resposta em Portugol

algoritmo "fatorial"

var
   numero, i, fatorial: inteiro

inicio
   escreva("Digite um número inteiro não negativo: ")
   leia(numero)

   fatorial <- 1

   para i de 1 ate numero faca
      fatorial <- fatorial * i
   fimpara

   escreval(numero, "! = ", fatorial)

Questão 7

Questão 7 — Média da turma

Leia a quantidade de alunos de uma turma. Em seguida, leia a nota de cada aluno e calcule a média geral da turma.

Resposta em Portugol

algoritmo "media_turma"

var
   quantidade, i: inteiro
   nota, soma, media: real

inicio
   escreva("Digite a quantidade de alunos: ")
   leia(quantidade)

   soma <- 0

   para i de 1 ate quantidade faca
      escreva("Digite a nota do aluno ", i, ": ")
      leia(nota)
      soma <- soma + nota
   fimpara

   media <- soma / quantidade
   escreval("Média da turma = ", media)

Leia a quantidade de alunos de uma turma e a nota de cada aluno. Considere aprovado quem tiver nota maior ou igual a 7. Ao final, informe a quantidade de aprovados e reprovados.

Questão 9

Questão 9 — Menu de operações

Crie um menu que seja exibido repetidamente até o usuário escolher a opção 4 - Sair:

  1. Somar dois números;
  2. Subtrair dois números;
  3. Multiplicar dois números;
  4. Sair.

Para as opções 1, 2 e 3, solicite dois valores e apresente o resultado.

Resposta em Portugol

algoritmo "menu_operacoes"

var
   opcao: inteiro
   a, b: real

inicio
   repita
      escreval("1 - Somar")
      escreval("2 - Subtrair")
      escreval("3 - Multiplicar")
      escreval("4 - Sair")
      escreva("Escolha uma opção: ")
      leia(opcao)

      se opcao >= 1 e opcao <= 3 entao
         escreva("Digite o primeiro valor: ")
         leia(a)
         escreva("Digite o segundo valor: ")
         leia(b)
      fimse

      se opcao = 1 entao
         escreval("Resultado: ", a + b)
      senao
         se opcao = 2 entao
            escreval("Resultado: ", a - b)
         senao
            se opcao = 3 entao
               escreval("Resultado: ", a * b)
            senao
               se opcao <> 4 entao
                  escreval("Opção inválida.")
               fimse
            fimse
         fimse
      fimse

   ate opcao = 4

   escreval("Programa encerrado.")

Questão 10

Questão 10 — Sequência de Fibonacci

Leia a quantidade de termos e apresente a sequência de Fibonacci, iniciando por 0 e 1. Exemplo para 8 termos: 0 1 1 2 3 5 8 13.

Resposta em Portugol

algoritmo "fibonacci"

var
   quantidade, i, a, b, proximo: inteiro

inicio
   escreva("Digite a quantidade de termos: ")
   leia(quantidade)

   a <- 0
   b <- 1

   se quantidade >= 1 entao
      escreva(a, " ")
   fimse

   se quantidade >= 2 entao
      escreva(b, " ")
   fimse

   para i de 3 ate quantidade faca
      proximo <- a + b
      escreva(proximo, " ")
      a <- b
      b <- proximo
   fimpara

   escreval("")
