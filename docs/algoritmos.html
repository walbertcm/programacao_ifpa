Material da Disciplina de Algoritmos

Os conteúdos foram organizados de forma progressiva, iniciando pelos conceitos básicos de programação, como variáveis, operadores e estruturas condicionais, avançando para estruturas de repetição, vetores e resolução de problemas computacionais.

As videoaulas disponíveis no canal do YouTube auxiliam na compreensão das listas de exercícios, apresentando o desenvolvimento dos algoritmos e estratégias de resolução utilizando VisualG e lógica de programação.

Orientações de Estudo

Recomenda-se iniciar pelas atividades introdutórias e avançar gradualmente para os exercícios mais complexos. Após resolver cada lista, utilize as videoaulas como apoio para revisar conceitos, comparar soluções e compreender diferentes estratégias de resolução.
